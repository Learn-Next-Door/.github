# Learn Next Door

**The local education marketplace connecting students with nearby tutors, coaches, and class providers.**

We help people discover music, dance, sports, academics, coding, arts, and more — right in their neighborhood.

---

## What We Build

Learn Next Door is a platform where:

- **Students** can search and discover local classes and tutors near them
- **Providers** can list their classes, manage bookings, and grow their business
- **Admins** can verify providers (KYC), manage listings, and keep the platform healthy

---

## Tech Stack

| Layer | Technology |
|---|---|
| Frontend | Next.js 16, React 19, TypeScript |
| Auth | Supabase Auth |
| Database | PostgreSQL via Prisma ORM |
| Monorepo | Turborepo + npm Workspaces |
| Deployment | Vercel |
| Maps | Google Maps / Leaflet |
